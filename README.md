# Методы статического анализа и качество Python-кода — курсовая Марины

**Учебный проект к курсовой** «Применение методов статического анализа для оценки качества и надёжности программного кода». Репозиторий не связан с другими курсовыми.

Проект включает безопасный сервис заявок, воспроизводимый AST-анализ пяти признаков потенциально проблемного кода и примеры **до/после**. Анализ *не выполняет* исследуемый файл и не является доказательством отсутствия уязвимостей.

## Состав

- `src/static_guard/` — ядро сервиса заявок и учебный AST-анализатор.
- `samples/before.py` — **намеренно небезопасный** образец только для статической проверки, запускать его не следует.
- `samples/after.py` — исправленный образец без выявляемых пяти шаблонов.
- `tests/` — проверки ядра и детектора (`unittest`).
- `tools/compare.py` — воспроизводимое сравнение количества срабатываний.
- `.github/workflows/quality.yml` — последовательность проверок GitHub Actions.
- `docs/METHODOLOGY.md` — протокол оценки и ограничения выводов.

## Локальный запуск без сторонних библиотек

Python 3.11+. Из корня распакованного проекта:

```bash
python -m pip install --no-build-isolation -e .
python -m unittest discover -s tests -v
python tools/compare.py
python -m static_guard samples/before.py
```

Для установки из сети и анализа Ruff/Bandit:

```bash
python -m pip install -r requirements-dev.txt
ruff check src/static_guard samples/after.py tools/compare.py
bandit -q -r src/static_guard samples/after.py
```

Шаблоны `samples/before.py` **исключены** из проверок качества исправленной версии: в нём диагностические ошибки оставлены специально для учебного сравнения.

## Результаты и ограничения

Учебный AST-анализатор проверяет 5 шаблонов: `eval`, `shell=True`, строковые значения переменных с определёнными именами секретов, `except:` без типа, изменяемые значения аргументов по умолчанию. Для этого образца ожидается 5 срабатываний в `before.py` и 0 в `after.py`.

Это число относится только к **пяти выбранным правилам**. Отсутствие срабатываний не гарантирует безопасность или надёжность программы. Ruff и Bandit являются дополнительными реальными линтерами с собственными наборами правил; их результаты не приравниваются к числам AST-демонстрации.

До публикации на GitHub можно проверить локальные `unittest` и учебный сканер. Прохождение GitHub Actions подтверждается **только после реального запуска** в созданном репозитории.

## Публикация на GitHub

Создать отдельный публичный репозиторий, распаковать ZIP и загрузить **содержимое проекта с сохранением каталогов** `src`, `samples`, `tools`, `tests`, `docs`, `.github/workflows`. Не загружать ZIP как единственный файл. После публикации проверить вкладку Actions; при необходимости исправить замечания и только потом добавлять ссылку и QR-код в Word.
